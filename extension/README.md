# SearchJev（Firefox拡張）

Google検索結果を TypeSafe の Jev で判定し、量産記事を下げ、一次情報を上げる拡張です。Firefox デスクトップ版と Android 版に対応します。

## インストール

- 公開後：addons.mozilla.org で「SearchJev」を検索してインストール（Android版Firefoxも同じ）
- 開発中：Firefox で `about:debugging#/runtime/this-firefox` →「一時的なアドオンを読み込む…」→ このフォルダの `manifest.json`

インストール後、ツールバーの SearchJev アイコンから設定を開き、TypeSafe の APIキーを入力します。

## 仕組み

- `content.js`：検索結果（PC版は h3、スマホ版は role="heading"）のタイトル・説明文・ドメインを読み取り、点数を表示して並べ替える。広告や「関連する質問」などは位置を変えない
- `background.js`：Jev を呼ぶ（1件につき1回、並列）。結果は 7 日間キャッシュ。本文モードでは記事ページを Cookie なしで取得して判定し直す
- `bodytext.js`：記事ページから本文の冒頭・見出し・公開日を取り出す（検証スクリプト `poc/fetch-bodies.mjs` と共有）
- `defaults.js`：既定の重み・プリセット・総合点の計算
- `options.html`：APIキー、記事の種類ごとの扱い、本文モード、重み（プリセット・プレビュー付き）

### 判定内容（`poc/` の手ラベル206件で検証）

各結果に 0〜100 の項目別スコア（すべて高いほど良い）を付け、その重み付き平均を「総合」とします。

| 表示 | 中身 | 既定の重み |
|---|---|---|
| 非量産 | SEO・アフィリエイト目的の量産記事らしくなさ | 2 |
| 一次情報 | 公式・公的機関・実体験・独自データ・専門家の度合い | 0.5 |
| 非商業 | 購入・申込への誘導が主目的でないこと。一次情報が高いページは減点を弱める | 1 |
| （非表示） | Googleの元の順位 | 1 |
| 関連 | 検索語の疑問に答えていそうか | 0（1.0/3 未満は最下位へ） |
| 記事の種類 | 解説・比較・体験談/口コミ・ニュース・公式・動画・その他の7種類。種類ごとに上げる/そのまま/下げる | 1 |
| 意図一致 | 検索した人が求める種類（検索語ごとに判定）と記事の種類の一致度 ＝ Σ 求める確率×その種類である確率 | 0.5 |
| 日付・古い可能性 | 説明文やページの日付と、話題の古くなる速さ | 既定では表示のみ |

検証結果（AUC＝「良い」と「ゴミ」を見分けられる確率）：Googleの順位 0.71、タイトルのみ 0.857、記事の種類あり 0.864、本文モード 0.881。

## 送信されるデータ

検索語と、検索結果のタイトル・説明文・ドメイン・URLのパスが api.typesafe.ai に送られます。本文モードのときだけ、記事ページの本文の冒頭（約2,500文字）と見出しも送られます。APIキーと設定はブラウザ内にだけ保存されます。詳しくは `../store/privacy-policy.md`。
